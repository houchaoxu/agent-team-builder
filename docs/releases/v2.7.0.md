## 角色由你选择，安装由你确认

找到更合适的专家后，Agent 会主动展示候选，等待你选择和确认，再安装并使用。

### 本次更新

- **选择合适的角色**：展示最多 3 个语义匹配角色，附推荐理由、来源和安装状态；可选择角色，也可跳过安装。宿主支持交互问答时呈现可点击选项，否则使用编号列表。
- **安装前手动确认**：选中角色后先展示具体安装预览，说明来源、项目路径和写入权限；只有你明确确认才安装。默认预选、匹配缓存或过去的泛化授权都不代表同意。
- **专业能力继续用于任务**：安装后核对宿主能力。尚未发现同名原生角色时，可由宿主支持的通用子 Agent 携带专业指令执行，或由主 Agent 顺序执行，并说明真实执行方式。
- **更清晰的项目介绍**：精简中英文 README，突出对话安装、按需协作、团队复用、角色推荐和项目记忆。

简单任务仍由主 Agent 直接完成；已有合适角色继续复用，不为每次任务扫描角色库。

### 安装与升级

新用户在项目中告诉 Agent：

> 请从 https://github.com/houchaoxu/agent-team-builder 安装最新稳定版，按照 INSTALL.md 完成环境准备并验证。

已安装 2.6.0 的用户可以说：

> 把当前使用的 Agent Team Builder 更新到最新稳定版，保留回退备份并验证版本。

2.5.x 及更早版本需先验证旧安装来源、完整备份，再迁移一次；详见[更新与回退](https://github.com/houchaoxu/agent-team-builder/blob/v2.7.0/agent_team/skill/references/updates.md)。

附件包含完整 Skill：`agent-team-runtime-skill.zip` 及 SHA-256 校验文件。实际宿主加载与原生可调用性仍需验证。

### 验证

- 可点击 UI 由宿主渲染；真实按钮点击回传尚未做前向验收。

## Choose the specialist. Confirm the installation.

- Get up to three semantic matches with reasons, sources, and installation status. Interactive hosts offer clickable choices; other hosts use a numbered list. Skipping installation is always available.
- Choose a role, review its source and project write scope, then explicitly confirm installation. Selection, preselection, cached judgments, and past broad authorization do not approve a new installation.
- Use installed specialist instructions even before native discovery: through a supported generic subagent or sequential execution by the main agent, with the actual executor identified.
- Refreshed English and Chinese READMEs focus on conversational setup, on-demand collaboration, reusable teams, role matching, and project memory.

Existing suitable roles are reused, and simple tasks stay with one agent. Version 2.6.0 installations can upgrade through conversation; versions 2.5.x and earlier require a verified, backed-up migration first. Download the complete Skill ZIP and SHA-256 file below.

Validation: 209 regression tests and 81 independently rerun targeted tests passed. Actual host button rendering and click handling have not been forward-tested.
