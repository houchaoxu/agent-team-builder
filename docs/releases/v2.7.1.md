## 修复：匹配到角色后正确提供安装选项

修复在 Codex 中发现 Claude 等其他宿主的角色素材时，将其误认为当前宿主已安装角色的问题。例如 UI Designer 以前可能显示“有记录但不可调用”，同时被 Agency 搜索去重过滤，导致无法继续选择安装。

- **正确区分来源**：其他宿主的角色显示为可导入素材，选择后可以预览并手动确认安装到当前项目。
- **保留 Agency 候选**：其他宿主的同名素材不再排除 Agency-Agents 角色库中的候选。
- **优先当前宿主定义**：多处存在相同角色 ID 时，优先当前宿主的个人角色定义，已有合适角色继续复用。
- **保护已有文件**：导入不会修改原宿主的角色文件；实际原生调用仍须验证宿主能力，安装前仍需用户确认。

本次保留现有角色发现范围，尚未将素材来源收敛为仅 Agency-Agents，也没有新增独立索引同步功能。

### 安装与升级

已安装 2.6.0 或 2.7.0 的用户可对 Agent 说：

完整回归 218 项通过；独立审查相关专项 90 项通过。覆盖跨宿主识别、同 ID 优先级、Agency 去重、预览确认与保留原文件的导入流程。真实宿主按钮点击和原生角色重载未做本次前向验收。

## Fix: offer installation for matching roles from other hosts

Roles discovered in another host's personal directory were incorrectly treated as already installed for the current host. A matching UI Designer could appear unavailable while its Agency counterpart was excluded from search results.

- Treat other hosts' definitions as importable material, with project installation after preview and manual confirmation.
- Keep matching Agency candidates visible when only another host's copy exists.
- Prefer the current host's personal definition when role IDs overlap.
- Preserve original role files and continue requiring actual host evidence for native invocation.

This patch retains existing discovery sources; an Agency-only catalog and independent index synchronization are not included.

Ask your agent to update the selected installation to v2.7.1 and keep a rollback backup. The complete Skill ZIP and SHA-256 file are attached below.

Validation: 218 regression tests and 90 independently rerun targeted tests passed. Actual host button clicks and native role reloading were not forward-tested in this patch.
